| Method | Route | Auth | Purpose |

| `PUT` | `/api/products/:id` | Yes (admin) | Edit product |

## Data Models

### User
```javascript
{
  _id: ObjectId,
  email: String (unique, required),
  emailVerified: Boolean (default: false),
  passwordHash: String,
  name: String,
  phone: String,
  createdAt: Date,
  role: String (default: "customer" | "admin")
}
```

### Product
```javascript
{
  _id: ObjectId,
  title: String,
  description: String,
  price: Number (smallest currency unit),
  images: [String] (Cloudinary URLs),
  sizes: [String] (e.g. ["S","M","L","XL"]),
  sizeGuideNote: String (optional),
  stock: [{ size: String, inStock: Boolean }],
  tags: [String],
  active: Boolean (default: true),
  createdAt: Date
}
```

### Order
```javascript
{
  _id: ObjectId,
  userId: ObjectId (ref User),
  items: [{
    productId: ObjectId,
    title: String,
    size: String,
    quantity: Number,
    priceAtOrder: Number (snapshot)
  }],
  totalAmount: Number,
  deliveryAddress: String,
  contactPhone: String,
  status: String ("pending_payment" | "awaiting_confirmation" | "paid" | "fulfilled" | "cancelled"),
  paymentMethod: String (default: "bkash"),
  paymentNote: String (optional),
  createdAt: Date,
  paidAt: Date (optional),
  fulfilledAt: Date (optional)
}
```

**Status values:**
- `pending_payment` — Order placed, awaiting owner to contact customer
- `awaiting_confirmation` — Owner contacted, waiting for bKash payment
- `paid` — Payment confirmed manually
- `fulfilled` — Shipped
- `cancelled` — Cancelled by customer or owner

### NewsletterSubscriber
```javascript
{
  _id: ObjectId,
  email: String (unique, required),
  subscribedAt: Date
}
```

**Note:** Skipped for V1. Brevo is source of truth.

## Design Decisions

### Brand Direction
- **Aesthetic:** Modern Japanese streetwear — Harajuku energy, dark base
- **Logo approach:** Keep both — refined logo as fixed mark (header, favicon), streetwear energy on product/marketing pages
- **Base color:** Near-black (warm or cool off-black, TBD exact hex)
- **Accent color:** Cobalt Blue — used for CTAs, hover states, sale badges, out-of-stock treatment
- **Text color:** Off-white/paper-white (not stark #FFFFFF)

### Typography
- **Display:** Bebas Neue — tall condensed, streetwear energy
- **Body:** Inter — clean, readable, broad character support
- **Japanese text:** Deferred to post-V1

### Visual Elements
- **Grain/Noise overlay:** CSS texture on dark background, included in V1
- **Product grid:** Mixed layout — mostly uniform with occasional featured items spanning two columns
- **Product cards:** Hover = scale + cobalt border flash
- **Out-of-stock:** Desaturated cobalt blue (not generic gray)
- **Gallery:** Thumbnail strip — horizontal scrollable thumbnails, main image above
- **Animation:** Framer Motion staggered reveals on product grid

### Authentication
- **Strategy:** JWT access + refresh tokens
- **Storage:** httpOnly cookies (not localStorage)
- **Password:** bcrypt hashing
- **CSRF:** Protection on state-changing routes

### Payment
- **Method:** Manual bKash, off-platform
- **No automated gateway:** Deliberately deferred, not forgotten
- **You are the payment step:** Required manual confirmation for every order

### Contact
- **Customer contact:** Plain wa.me and m.me links (not Business APIs)
- **Placeholders:** WhatsApp number and Facebook Page name TBD before launch
