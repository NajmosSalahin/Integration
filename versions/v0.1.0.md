## API Endpoints

### Auth Routes

| Method | Route | Auth | Purpose |
|---|---|---|---|
| `POST` | `/api/auth/signup` | No | Create account |
| `POST` | `/api/auth/verify-email` | No (token) | Confirm email via link |
| `POST` | `/api/auth/login` | No | Log in, set JWT cookie |
| `POST` | `/api/auth/logout` | Yes | Clear JWT cookie |
| `POST` | `/api/auth/forgot-password` | No | Send password reset email |
| `POST` | `/api/auth/reset-password` | No (token) | Set new password |
| `POST` | `/api/auth/refresh` | No (httpOnly cookie) | Refresh access token |
| `GET` | `/api/auth/me` | Yes | Get current user |

### Product Routes

| Method | Route | Auth | Purpose |
|---|---|---|---|
| `GET` | `/api/products` | No | List all active products |
| `GET` | `/api/products/:id` | No | Single product detail |
| `POST` | `/api/products` | Yes (admin) | Create product |
| `PUT` | `/api/products/:id` | Yes (admin) | Edit product |
| `PATCH` | `/api/products/:id/stock` | Yes (admin) | Flip a size's `inStock` boolean |
| `DELETE` | `/api/products/:id` | Yes (admin) | Soft delete (set active: false) |
| `GET` | `/api/products/admin/all` | Yes (admin) | List all products including inactive |

### Order Routes

| Method | Route | Auth | Purpose |
|---|---|---|---|
| `POST` | `/api/orders` | Yes | Create order from cart → triggers emails |
| `GET` | `/api/orders/mine` | Yes | User's own order history |
| `GET` | `/api/orders` | Yes (admin) | List all orders |
| `PATCH` | `/api/orders/:id/status` | Yes (admin) | Update order status |

### Contact & Newsletter Routes

| Method | Route | Auth | Purpose |
|---|---|---|---|
| `POST` | `/api/contact` | No | Contact form → emails owner |
| `POST` | `/api/newsletter/subscribe` | No | Add contact to Brevo list |

## Data Models

### User
```js
{
  _id: ObjectId,
  email: String (unique, required),
  emailVerified: Boolean (default: false),
  passwordHash: String,
  name: String,
  phone: String,
  role: String ("customer" | "admin"),
  verificationToken: String,
  verificationExpires: Date,
  resetPasswordToken: String,
  resetPasswordExpires: Date,
  createdAt: Date
}
```

### Product
```js
{
  _id: ObjectId,
  title: String,
  description: String,
  price: Number (in cents),
  images: [String],
  sizes: [String],
  sizeGuideNote: String,
  stock: [{ size: String, inStock: Boolean }],
  tags: [String],
  active: Boolean (default: true),
  createdAt: Date
}
```

### Order
```js
{
  _id: ObjectId,
  userId: ObjectId (ref User),
  items: [{
    productId: ObjectId,
    title: String,
  size: String,
    quantity: Number,
    priceAtOrder: Number
  }],
  totalAmount: Number,
  deliveryAddress: String,
  contactPhone: String,
  status: String ("pending_payment" | "awaiting_confirmation" | "paid" | "fulfilled" | "cancelled"),
  paymentMethod: String (default: "bkash"),
  paymentNote: String,
  createdAt: Date,
  paidAt: Date,
  fulfilledAt: Date
}
```

## Deploy Notes

- **Service:** Render (single web service, free tier)
- **Build:** `npm install && cd client && npm install --include=dev && npm run build && cd ../server && npm install`
- **Start:** `cd server && node server.js`
- **MongoDB:** Atlas free tier, cluster `ac-gbwyheo`
- **Brevo:** Free tier (300 emails/day)
- **Plausible:** Analytics script tag, data-domain set to Render URL
