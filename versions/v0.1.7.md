# Version 0.1.7

**Date:** 2026-09-15
**Status:** Pre-Release — v0.1.7 In Development

---

## Overview

Replaces the substring-only search with a fuzzy, relevance-ranked search that covers the whole active catalog (155 products) and is shared consistently by the Navbar live dropdown, the Home page, and the Shop page. Adds the FeaturedRow carousel and a two-per-row mobile grid on the homepage.

---

## Features Shipped

| Feature | Description | Status |
|---|---|---|
| Fuzzy client-side search | `client/src/lib/smartSearch.js` — Fuse.js wrapper with weighted keys (title w0.6, tags w0.25, description w0.15), threshold 0.4, `ignoreLocation`, `includeScore`; WeakMap-cached Fuse instance | ✅ |
| Shared search function | `searchProducts(products, query, limit)` used by Navbar, Home, and Shop; returns original array on empty query (no behavior change for browsing) | ✅ |
| Navbar debounce | `useDebouncedValue(value, 250)` hook (`client/src/hooks/useDebouncedValue.js`) — dropdown updated only after 250ms of no input | ✅ |
| Navbar dropdown ≤6 | `SearchResults` receives up to 6 fuzzy-matched products from the debounced query; Enter still navigates to `/shop?q=...` | ✅ |
| Home search via description | Home now matches queries against title + tags + description; displayed results capped at 16 as before | ✅ |
| Shop relevance-ordered search | When `?q=` is present, results come from `searchProducts` (Fuse score) and are not re-sorted by the dropdown; sort dropdown only applies when no search query is active | ✅ |
| `description` exposed in API | `server/controllers/productController.js` — public `getProducts` projection now includes `description` (no schema change, no new endpoint) | ✅ |
| FeaturedRow carousel | `FeaturedRow` component renders featured products; homepage shows the row above the Collection grid | ✅ |
| Two-per-row mobile grid | Homepage product grid uses `grid-cols-2 lg:grid-cols-4` | ✅ |
