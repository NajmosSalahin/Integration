# Version 0.1.3

**Date:** 2026-09-13
**Status:** Stable — v0.1.3 Complete
**Codename:** Integration — Literature Cover Series

## Overview

Adds 49 new products across two fronts: a brand-new **Literature Cover T-Shirt** category (31 Bengali literature book-cover designs) and 18 new aesthetic t-shirt designs. Product catalog grows from 55 → 104. New category is live across the homepage grid, Shop sidebar, and mobile pills.

| Issue | Fix |
|---|---|
