# Version 0.1.1

**Date:** 2026-09-12
**Status:** Stable — v0.1.1 Complete
**Codename:** Integration — Real Product Images

---

## Overview

Wires up Cloudinary (previously installed but never configured), uploads the 17 real product designs, and replaces the placeholder seed catalog with actual products at a flat 450 BDT price.

---

## Features Shipped

| Feature | Description | Status |
|---|---|---|
| Cloudinary Config | `server/utils/cloudinary.js` — SDK config from env vars | ✅ |
| Upload Pipeline | `server/utils/uploadImages.js` — copies each image ×3, uploads all 51 PNGs, saves URL map | ✅ |
| `seed:upload` script | Root npm script to run the upload pipeline | ✅ |
| Real Seed Data | `server/utils/seed.js` — 17 products (7 plain + 10 IU-themed), 450 BDT, 3 images each, sizes S–XL | ✅ |
| URL Artifact | `server/utils/uploaded_urls.json` — generated map of product → Cloudinary URLs | ✅ |
| Env Fix | Cloudinary cloud name corrected to `zo1t9pye` in development/production/render envs | ✅ |
