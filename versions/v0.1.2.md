# Version 0.1.2

**Date:** 2026-09-12
**Status:** Stable — v0.1.2 Complete
**Codename:** Integration — Category Taxonomy

---

## Overview

Introduces a 17-category product taxonomy shared across the site. The homepage shows only relevant categories (in-stock + hand-picked), while the Shop page exposes all categories via a desktop sidebar and mobile pills. Product tags are migrated to match.

---

## Features Shipped

| Feature | Description | Status |
|---|---|---|
| Category Config | `client/src/data/categories.js` — 17 categories `{ name, tag, icon, home }` | ✅ |
| Homepage Grid | `CategoryGrid.jsx` — shows `home: true` categories, real image from first matching product, icon placeholder for empty ones | ✅ |
| Shop Sidebar | `Shop.jsx` — desktop left sidebar with all 17 categories + "All" | ✅ |
| Mobile Pills | `Shop.jsx` — horizontal scrollable category pills on small screens (replaces raw-tag bar) | ✅ |
| Taxonomy Tags | Products re-tagged `iu-tshirts`, `mens-tshirts`, etc. (descriptive tags retained) | ✅ |

## Bug Fixes

| Issue | Fix |
|---|---|
| Category images never loaded — tags `t-shirts`, `hoodies`, `shirts` had no matching products | Categories now use product taxonomy tags; images pull from first matching product |
