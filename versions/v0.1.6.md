## Data Model Changes

```
Product: {
  featured: Boolean — flag already existed in schema but was never set by the seeder
}
```

**Added:**
- No schema fields added.

**Modified:**
- `featured` — the seeder previously never copied the `featured` flag from seed arrays into product documents, so every product defaulted to `false`. Now `buildProducts()` propagates `featured: !!seedRecord.featured`.

- Nothing removed.
